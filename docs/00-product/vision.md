# Visión del producto

## Qué es

VALME Search OS es el sistema operativo de una agencia SEO, AEO y GEO semiautomatizada. Centraliza onboarding, diagnóstico, estrategia, tareas, aprobaciones, ejecución controlada e informes.

## Usuario principal

El Project Manager. La interfaz debe permitirle comprender el estado de cada cliente, revisar propuestas de IA y aprobar o rechazar acciones sin conocimientos técnicos avanzados.

## Principio central

**La IA propone y prepara; el Project Manager decide.**

## Resultados que debe producir

- Onboarding estructurado.
- Auditoría inicial.
- Estrategia de 90 días.
- Backlog priorizado.
- Seguimiento de SEO, AEO y GEO.
- Informes comprensibles para el cliente.
- Historial de decisiones y aprobaciones.

## Fuera de alcance en la primera versión

- Publicación automática en webs de clientes.
- Cambios automáticos de presupuesto.
- Envío automático de informes sin revisión.
- Acceso de escritura a herramientas externas.
- Facturación y gestión comercial completas.

## Criterio de éxito del MVP

Un Project Manager puede dar de alta un cliente, recibir un plan propuesto, revisar tareas y preparar un informe desde una sola interfaz.
